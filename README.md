## Important note about hover autoplay
Google Drive's embedded preview player does not expose reliable true muted autoplay-on-hover controls like a self-hosted HTML5 `<video>` file would. V2 therefore loads the Drive player automatically on hover, after which its own player controls are available.

For genuine instant silent motion previews on hover, add small compressed preview MP4/WebM files to the website repo later. The site can then use native `<video autoplay muted loop>` previews while keeping the full-quality videos on Drive.

## GitHub Pages
